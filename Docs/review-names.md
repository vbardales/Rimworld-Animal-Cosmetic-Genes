# Official names in game texts

Proper names that appear in the game texts (Mod/ XML outside About, comments removed) and exist outside RimWorld. Official form = title of the fr.wikipedia article. Checked 2026-11-13.

| Name in game text | French text | fr.wikipedia article | Verdict |
|---|---|---|---|
| Midas (midas gold coat) | pelage or de Midas | Midas | official, same |
| Gulf Stream (gulfstream coat) | pelage Gulf Stream | Gulf Stream ("courant du Golfe" is the alias) | official, same |
| Mars (mars red coat) | pelage rouge de Mars | Mars (planète) / Mars (mythologie): base name Mars | official, same; the pigment article is "Couleurs de Mars", "rouge de Mars" is the usual colour name |
| Maui (maui surf coat) | pelage écume de Maui | Maui (the island); the demigod is "Maui (mythologie)" | official, same |

Other names in the texts (Biotech, Xenogermination, mod titles) are not game text or are def references: nothing to decide.
